# 🔐 PassVault — Secure Desktop Password Manager

A lightweight, secure desktop password vault built in Python featuring 256-bit AES encryption.

## ✨ Features
* **256-Bit AES Encryption:** All passwords are encrypted locally using master password key derivation.
* **Master Password Lock:** Clean graphical user interface for seamless lock/unlock.
* **Local Storage:** Zero cloud dependencies—your data stays strictly on your device.

## 🛠️ Built With
* **Python**
* **Cryptography / Fernet**
* **Tkinter / GUI**
